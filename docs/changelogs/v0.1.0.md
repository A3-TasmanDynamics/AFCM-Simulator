# Changelog — v0.1.0

Every addon still reports `version = "0.1.0"` (`CfgPatches`, all ten PBOs) — no version bump or
tag has been cut yet, so this file covers the whole of development to date under that one version.
Entries are sourced directly from the real git history (`git log`), newest first, one section per
day of activity. When a later version ships, it gets its own `vX.Y.Z.md` file in this folder.

---

## 2026-09-01

**Added**
- **Medical Tent** — session-scoped treatment-completion detection built on top of Spawn Sessions.
  `AFCM_SIM_ModuleMedicalTent` (Eden): sync any stretcher objects from a mission maker's own
  composition to it (AFCM spawns no tent/scenery of its own). A Spawn Session resolves once every
  live patient in it is both **treated** (auto-detected via live medical state, or manually via a
  new "Mark as Treated" action) and within **Stretcher Radius** of a synced stretcher — one shared
  server-side monitor loop covers every placed tent at once, so multiple simultaneous tents/sessions
  resolve independently. Resolution shows a new custom AFCM-branded **toast** notification
  (`RscTitles`/`cutRsc` — a passive HUD overlay that never steals input focus from Zeus, unlike a
  dialog) and republishes `session.resolved` on the UI event bus for a mission's own AAR/scoring
  logic to subscribe to. *(`a81d584`)*
- **Interactive Terminal** module (`AFCM_SIM_ModuleInteractiveTerminal`, Eden/Zeus) — sync it (or
  drag it directly onto an object in Zeus) to any placed object, e.g. a Laptop, and every player
  gets two real scroll actions on it: "AFCM: Open MCI Creator" / "AFCM: Open Session Manager" — a
  diegetic way into the tool kit for a training scenario that doesn't need the CBA keybind or Zeus
  itself. *(`cc721f3`)*
- **Zeus "Edit Injuries" module** (`AFCM_SIM_ModuleEditInjuries`, `curatorCanAttach = 1`) — drag it
  directly onto any unit to open the Injury Editor immediately, reaching units that never got the
  "Edit Injuries" scroll action (only AFCM-spawned patients get that). Grounded in ACE3's own Zeus
  "Heal" module pattern (`attachedTo _logic` for the target, a `local _logic` guard so the dialog
  opens only on the placing curator's machine, then self-deletes). *(`0492d9b`)*

## 2026-08-30 (Spawn Sessions + MCI Creator hardening)

**Added**
- **Spawn Sessions** — every batch of patients spawned together (a Zeus/Eden MCI Spawner, an MCI
  Creator incident, an AFCM MASCAL Zone) is now grouped into a named session
  (`[id, label, spawnTime, units]`, `AFCM_SIM_spawnSessions`), independent of the existing flat
  patient list. New **Session Manager** dialog lists sessions and deletes one at a time without
  touching any other session's patients (e.g. two medics each working their own MCI at once); a new
  generic, reusable **Confirm dialog** (Yes/No) gates the one remaining fully-destructive action,
  "Clear All Sessions." Bound to a new CBA keybind, default Ctrl+Shift+O. *(`92b93a6`)*
- **Optional custom session names** — every batch spawn path (Zeus/Eden Spawn Patient, MASCAL Zone,
  MCI Spawner, and the MCI Creator dialog) now accepts a free-text label overriding the
  auto-generated one when non-blank, via a shared `AFCM_SIM_SessionName` Eden Attribute
  (`control = "Edit"`) or a matching field on the MCI Creator. *(`e1faf99`)*
- A real marker now drops on the Map Picker at the spot you click, so the pick is visually
  confirmed before spawning. *(`b26e023`)*
- MCI Creator: multi-limb toggle-select + apply in the injury editor, and patient count 1–10.
  *(`739e82f`)*
- **MCI Creator** — a standalone tool: pick a patient count, assign each patient its own Injury
  Preset (or "random") independently, pick a spot on a real interactive map
  (`RscMapControl`-based Map Picker), spawn the whole incident in one request. *(`45bf860`)*
- **MCI Spawner** modules (Zeus + Eden) — spawn a batch of patients and apply one Injury Preset to
  the whole group at once; injury editor gained a Back button. *(`a10db6b`)*
- **Injury Presets** — create, save, apply, export, and import named injury configurations, built-in
  + a per-player `profileNamespace` user library. *(`8a5e301`)*
- Real KAT-specific **Fracture/Pneumothorax** injuries, wired into the injury editor. *(`cf63e00`)*
- Configurable **Casualty Type** (clothing/appearance) on every spawn path, and patients now spawn
  stripped to bare clothing. *(`d5274c5`)*
- Backend-aware injury editor — real ACE/KAT wound-type selections, KAT-only controls shown only
  when KAT is the active backend. *(`0a771a8`)*

**Fixed**
- KAT Fracture restricted to arms/legs only (not head/chest — KAT's own array has slots for both,
  but this project deliberately excludes them). *(`a0dc9f3`)*
- MCI Eden preset-injuries type mismatch (raw Array vs. required Injury HashMap) and a missing
  module re-fire guard. *(`c85b10f`)*
- UI dialogs re-centered on screen; Reset split into per-limb (local, non-destructive) and
  per-patient (full reset) actions. *(`7f3ef44`)*
- **Patients healing themselves — real root cause found and fixed**: engine `setUnconscious` was
  fighting ACE's own `ACE_isUnconscious` tracking. Redesigned the affected UI dialogs at the same
  time. *(`5c2810f`)*
- Reverted a brief 13-region `LimbId` experiment back to the original 6 values (a direct 1:1 match
  to ACE3's real body parts) after `0a771a8`/`19148c4` explored KAT-only controls. *(`039b578`)*
- Reverted a recurring unconscious-lock safeguard; injury editor's wound-type list went back to
  ACE-only pending further work. *(`19148c4`)*

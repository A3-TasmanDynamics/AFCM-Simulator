# AFCM-Simulator — Update (2026-10-29)

**Added:**
- Mark as Treated / Export Patient State scroll actions can now be toggled off in Addon Options, and now respect the same "Require Injury Edit Permission" setting as Edit Injuries
- Injury Author: settable Pain Level alongside Blood Volume/SpO2, an "Advanced Adjustments" section header, and mouseover tooltips
- Injury Author: consciousness is now a clean checkbox, staged until you hit Apply — ticking it no longer forces the patient's state immediately
- Injury Author's live status readout redesigned — clearer, color-coded, no longer overflows the box
- Double-click a preset to apply/assign it instantly (MCI Creator, Preset Library)
- Wound types list cleaned up to the exact real injury classes — Abrasion, Avulsion, Contusion, Crush, Cut, Laceration, Puncture Wound, Thermal Burn, Velocity Wound
- Zeus module icons — each module now has its own distinct icon instead of sharing one placeholder
- MCI spawning now supports a configurable spawn radius with a live circle preview on the map — settable from the MCI Creator window directly or the map picker. Patients scatter realistically within it instead of stacking on top of each other
- Zeus MCI Spawner: radius settable right on the module's own attributes too, and the location marker is pre-placed when you open the map
- Zeus Spawn Patient module now opens the Injury Author automatically right after spawning, and cleans up its own icon once placed
- Zeus Interactive Terminal now requires being placed on an object, and disappears once it's set up
- Random Damage renamed "Apply Random Damage" — now applies immediately and closes the dialog instead of just staging

**Changed/Fixed:**
- Fixed a crash ("parsenumber" error) when placing an AFCM Patient module or reloading a saved session in the editor
- Fixed the Injury Author navbar incorrectly highlighting adjacent limb buttons
- Clear All removed from the Injury Author — Reset Patient now reliably clears everything, including random damage rolls that were never applied
- Apply now closes the Injury Author dialog once it's done
- Preset Library / MCI Preset Library: Import/Apply and Import/Load button positions swapped

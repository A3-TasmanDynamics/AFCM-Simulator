# AFCM-Simulator — Update (2026-10-23)

**Added:**
- Patients now spawn with a random name on every path (Zeus, Eden, MCI Creator)
- AFCM Patient module (Eden): "Title" label for telling multiple placed patients apart, a paste-free "Training Preset" quick-pick, and syncing an object (a laptop, etc.) now gives it a repeatable "Spawn Patient" interaction instead of auto-spawning — configurable Scroll Wheel / ACE Interaction Menu / Both
- Spawn Marker Name(s) now takes a comma-separated list of exact marker names — one patient spawns at each, placed exactly on the mark
- Wound types expanded from 3 to 10 — Abrasion, Avulsion, Contusion, Crush, Cut, Laceration, and Thermal Burn added alongside Gunshot/Shrapnel/Blast
- Settable Blood Volume and SpO2 in the Injury Author, alongside the existing injury controls
- Medical terminals can grant (and revoke) a player's permission to edit patient injuries — optional, off by default
- Zeus MCI Spawner now opens the real MCI Creator on placement — give each patient their own distinct injuries, or load a saved MCI Preset, instead of one shared wound for the whole batch
- A full step-by-step Field Manual usage guide, plus a Steam Workshop page description

**Changed/Fixed:**
- Zeus modules (Spawn Patient, MCI Spawner, Edit Injuries) weren't actually placeable — fixed for real this time
- Interactive Terminal's Zeus "drag onto an object" placement made far more reliable
- Spawn Sessions now auto-clear once every patient in them is gone, including deleting a whole batch at once in Zeus
- Two or more AFCM Patient modules synced to the same object no longer cross-wire — each spawns its own correct patient
- Injury Author no longer loses track of a patient's current injuries when you back out and go back in
- MCI Creator no longer reuses a previous incident's injuries on a new spawn
- Eden's AFCM Patient module attributes (Title, Casualty Type, Session Name) now actually show up and apply correctly

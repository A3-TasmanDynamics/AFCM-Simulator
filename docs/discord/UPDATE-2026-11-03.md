# AFCM-Simulator — Update (2026-11-03)

**Added:**
- Zeus Spawn Patient module now has a real Unit Type dropdown — pick a faction, then pick a specific role (Rifleman, Medic, Officer, Engineer, Pilot, etc.) from that faction, just like the vanilla Reinforcements module

**Changed/Fixed:**
- Addon Options still weren't showing up in the Eden Editor — found the real cause this time (a missing CBA dependency) and fixed it
- AFCM Patient Module's Casualty Type/Training Preset dropdowns could silently store "true" instead of your actual selection — fixed
- Edit Injuries window: Unconscious checkbox moved to the right of its label, and the label now matches the Blood/SpO2 text styling
- Medical Terminal module: success/failure messages are now a quick hint instead of a big popup, and the module now disappears instantly when placed somewhere with nothing to attach to (instead of lingering for several seconds)
- Zeus Spawn Patient: fixed a bug where it wasn't actually opening the Edit Injuries window after spawning a patient like it was supposed to

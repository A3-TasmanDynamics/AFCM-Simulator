# AFCM-Simulator — Update (2026-10-29, part 2)

**Added:**
- Zeus Spawn Patient module now opens a picker to choose Casualty Type before anything spawns — and remembers your last choice for next time, so placing it again is a one-click repeat
- Consciousness toggle is a proper checkbox now, not a button styled to look like one
- Addon Options are now grouped into clear sections (General/Defaults/Interaction/Permissions/Training/Scenario) instead of a mostly-flat list
- Renamed "Interactive Terminal" to "Medical Terminal" everywhere — it now gives you a hint when it's set up correctly, and warns you if you drop it without attaching it to an object

**Changed/Fixed:**
- Addon Options weren't showing up in the Eden Editor at all (only in-game/main menu) — fixed
- Eden-placed AFCM Patient and Medical Terminal modules showed a solid black icon — fixed, both now show a proper icon
- Toast notifications (like "Nothing staged to export yet.") could render invisibly behind an open window — fixed, they now always show on top

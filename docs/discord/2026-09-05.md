# AFCM-Simulator — Injury Author Update (2026-09-05)

Following up on the Injury Author dialog release — a batch of stability fixes and refinements
based on real in-game testing feedback.

**Fixed 🔧**
- Two real crashes, both caught from an in-game RPT log: opening Injury Author via `Ctrl+Shift+I`
  could throw a hard error, and reselecting a limb with an existing wound in the navbar could also
  crash. Both root-caused and fixed — not workarounds.
- The navbar's flickering/false-highlight bug is *actually* fixed this time. The first pass only
  handled part of it; the real cause was native button hover effects painting over our own
  selection colors. Now fully suppressed on those buttons.
- `build.ps1 -Sign` no longer falsely claims "No signing key found" when a real signing key exists.

**Changed ⚙️**
- **Apply no longer closes the dialog.** Configure and apply/spawn multiple times in a row without
  reopening every time.
- **Closing the dialog no longer loses your work.** Back out to check something else, come back,
  and your in-progress setup — even if you never clicked Apply — is right where you left it. (This
  is separate from "Remember Last-Used Injuries," which is the longer-term, across-sessions version
  of this.)
- **Bleeding is now None/Small/Medium/Large**, matching ACE's own real wound-size categories
  exactly — no more guessing which of two options actually does the same thing under the hood.
- **Severity can now be left as "None"** — stage a real wound without being forced to also pick a
  severity right away; it'll use a sensible default if you don't.

**Added ➕**
- **"View Live State" button** — once you spawn a patient from the authoring flow, you can now
  watch their live medical status right there, without needing to reopen the dialog in edit mode.

**Docs 📚**
- Deep-dived into ACE3's actual source to confirm the real terminology and thresholds behind wound
  sizes and bleeding — fully documented in `ACE_COMPAT.md` for future reference.

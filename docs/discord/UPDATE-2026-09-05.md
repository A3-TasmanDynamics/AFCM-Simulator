# AFCM-Simulator — Update (2026-09-05)

**Added:**
- Injury Author tool — one screen to build a patient's injuries limb-by-limb (Head/Chest/Arms/Legs list on the side), nothing applied until you commit the whole set
- Author brand-new patients from scratch (`Ctrl+Shift+I`), pick a spawn location, and spawn them in fully configured
- Bleeding severity levels (None/Light/Medium/Heavy/Severe) instead of a plain on/off checkbox
- "None" wound option — leave a limb wound-free while still giving it something like an airway injury
- Random Damage button (Easy/Medium/Hard/Insane)
- "Remember Last-Used Injuries" option, with a one-click Clear All
- Export/Import a patient's exact injuries as a paste-able string (now also carries KAT fracture/pneumothorax/airway/cardiac state, not just base wounds)
- Cardiac arrest toggle (ACE) + real rhythm typing (KAT: Asystole/PEA/V-Fib/V-Tach)

**Changed/Fixed:**
- Eden editor's module list trimmed to remove duplicates already covered by Zeus
- Fixed a sync-to-position bug on the AFCM Patient module (syncing an object silently didn't work unless an easy-to-miss checkbox was also ticked)
- Fixed a button-flashing visual bug, mod-wide
- 8 stability fixes from a full review pass (injury application edge cases on live players, Medical Tent edge cases, a rare preset-saving collision risk, a few UI papercuts)
- Mod build is now signed — works correctly on servers that enforce signature checking

**Removed:**
- AFCM MASCAL Zone, AFCM MCI Spawner, and Medical Tent modules removed from the Eden editor (Zeus keeps its own versions where applicable)
- Old two-screen injury editor retired, replaced by the new Injury Author tool
